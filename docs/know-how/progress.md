# Where the author is, at all times

Making a book runs over weeks and many sessions. The author should never have to ask "where are we?" — every gate says it in one line before anything else.

## The stages

```
Planning ▸ Ch1 ▸ Ch2 ▸ … ▸ ChN ▸ Done
```

- **Planning** — everything `/kav-kickoff` covers: concept, cast, locations, style, visual lock, pitch, storyboard, package. Ends when **the story brief is published** and the author has read it. That is the gate, not an internal file write.
- **Ch1 … ChN** — one chapter at a time through `/kav-chapter`, each with the same five steps: **outline → picks → lettering → review → publish**.
- **Done** — the whole book is published, and the author is asked how it went (`/kav-publish`, the feedback pass).

## The header

Every gate — every message that asks the author to decide — opens with one line:

```
Kav · last-light · Ch3 (2 of 6) · picks    [Planning ✓ · Ch1 ✓ · Ch2 ✓ · Ch3 ▸ · Ch4–6 · Done]
```

Story slug, the stage, where it sits in the book, and the step inside the chapter. Keep it to one line, in the room's language, and never let it push the actual question down the screen.

## Where it lives

`kickoff-state.md` carries the same thing in writing, so a new session picks it up without re-reading the whole folder:

```
## Progress
Stage: Ch3 · picks · 2 of 6 chapters published
Planning: locked 2026-03-04 · brief published <url>
Chapters: ch01 published · ch02 published · ch03 picks · ch04–06 not started
Next gate: pick the takes for scenes 4–6
```

Update it at every stage change — it is the first thing read and the last thing written.

## Rules

- **Name the stage before the question,** not after the work.
- **"Proceed" means advance to the next real gate:** do the work, then present the artifact that can actually be judged, with its link, and say what decision is needed. It does not mean a text-only confirmation of what you are about to do.
- **Don't stop twice for the same decision.** A text-only stop immediately before generating the images that would answer the question is a wasted turn: when the story decision is approved, generate the batch and bring back the takes.
- **A chapter is finished when it is published**, not when the panels are lettered. The author should be able to read it on a phone before the next chapter opens.
